# LyLmecho 默认主题 · lylmeblog

> 把「导航」和「博客」放进同一套视觉与信息流里的 LyLmecho 主题。
> 皮肤基座与博客模块默认主题 LyLme Modern 完全同源，打开站点首页（`/`）与博客页（`/article/`）是同一款设计语言。

## 特性

- **同源皮肤**：复用 `LyLme Modern` 的后台 Lightyear 基座 + 皮肤（`css/base.css`、`js/script.js`），明暗主题、侧栏抽屉、滚动条、揭示动画与博客端完全一致。
- **首页即导航**：Hero 搜索区支持「搜索引擎 / 站内检索 / 博客文章」三种模式：
  - 全网引擎（后台「搜索引擎」管理）默认新窗口打开；
  - 「站内检索」对本页已收录链接做即时过滤，不跳页；
  - 启用博客后追加「博客文章」，直达博客搜索。
- **博客联动（方案 1）**：右侧栏固定展示博客信息卡、最新文章、热门文章、文章分类；顶部/侧栏提供「博客文章」「RSS 订阅」入口。
- **分组直达**：Hero 内嵌各分组快速定位 chips；主内容区以卡片网格分组展示全部链接。
- **主色同步**：主题配置里改主色后，导航首页与博客主题视觉变量保持同源。
- **返回互链**：博客端侧栏/页脚新增「返回导航首页」，双向闭环。

## 使用

1. 后台 → 系统设置 → 网站主题，选择 `lylmeblog`；
2. 后台 → 导航主题设置，可调整：
   - 主色、默认配色方案、链接网格列数；
   - 「首页显示模块」勾选 `博客联动区块 / 热门文章榜 / 顶栏时间`；
   - 首页公告（支持 HTML）、侧栏最新文章条数、公安备案号。
3. 确保已安装并开启「文章模块」（否则博客联动区块自动隐藏，首页仍为完整导航页）。

## 文件

```
index.php        页面主体（唯一页面）
functions.php    辅助函数 / 博客数据联动
config.php       主题配置表单
css/base.css     博客皮肤（与 article/theme/lylme/style.css 同源）
css/style.css    导航页专属样式（引擎、分组网格、小组件等）
js/script.js     博客交互脚本（与博客端同源）
js/nav.js        导航交互（引擎记忆、站内检索、顶栏时钟）
theme.ini        主题元信息
```

## 说明

- 依赖后台基座静态资源 `assets/admin/css|js`（Bootstrap/MDI/Lightyear）与导航图标 sprite `assets/js/icon.js`；
- 主题函数均以 `theme_` 前缀命名，全部兼容 PHP 5.4+；
- 博客数据均通过主题内独立 SQL 读取 `lylme_article*` 表，不存在该表或模块关闭时自动降级，不影响导航首页。
